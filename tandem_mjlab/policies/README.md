# 正式发布 policy 0.2.0

2026-10-08 按用户选择发布静止平滑版。`locomotion.onnx` 为唯一部署模型，`locomotion.pt` 是同一版本的续训 checkpoint。原 C4 网络权重保留，新增的静止平滑没有再次训练。

```bash
.venv/bin/mjpython -m tandem_mjlab.sim2sim --keyboard
```

默认前后 1 m/s、转向 2 rad/s。按住1/2前进/后退、3/4右转/左转，松开减速归零，可组合按键。

## 协议

- `obs`: float32 `[1,27]`；`obs_history`: float32 `[1,135]`；`actions`: float32 `[1,6]`。
- 观测顺序：机体角速度×0.25（3）、机体重力方向（3）、前向指令×2/偏航指令×0.25/标称高度×5（3）、四腿相对标称位置（4）、六关节速度×0.05（6）、上一帧策略输出（6）、航向误差sin/cos（2）。
- 历史按旧到新排列五帧，初始帧填满历史。转向时重设参考航向，转向结束后保持该航向。
- 动作顺序：左前腿、左后腿、右前腿、右后腿、左轮、右轮。腿目标偏移系数0.5rad，轮速度目标系数10rad/s；动作及力矩限幅来自 `model.py`。
- 策略周期20ms、物理步长0.5ms。前进和转向指令均归零时，四腿输出使用 `0.25×当前目标+0.75×上一帧输出`；轮控制保持原样，处理已包含在ONNX中。
- 模型使用 `MJCF/demo/demo.xml`，保留原始惯性、左右差异及四组闭链 equality；原始文件为 `demo_original.xml`。

## 评估与限制

发布路径重测30个工况，所有指标与此前静止平滑候选完全一致。60s静止最大位置偏移2.551mm；静止腿关节速度RMS约0.017rad/s，双轮持续接地。前后移动、正反转向与停车切换通过现有回归门槛。

**发布状态由用户确认，严格性能验收仍未全部通过。** +2m/s直行最大航向误差2.106°、横移/路程2.615%，超过2°/2%门槛。静止轮控制仍有小幅波动，偏航角速度MAE约0.035rad/s。没有实机、外扰或随机化域验收；本次没有执行完整40工况的`--final`评估。

哈希、来源和重构验证见 `metadata.json`；31个已测工况（30个标准工况与60s静止）的数据见 `evaluation.json`。重新生成CSV的命令见 [训练与评估](../README.md)。
